# niri session — port of the Hyprland setup

Started 2026-10-20 on niri 26.04. The config is `niri/.config/niri/`
(stow package `niri`). `config.kdl` is a table of contents. Each include
mirrors one Hyprland module and says where niri differs.

## Ideas that niri has and Hyprland did not

- **Fixed column widths.** A new window never resizes another one. The strip can
  be narrower than the screen. Fill it by hand: Mod+R presets, Mod+Ctrl+F
  expand, Mod+Shift+F maximize column.
- **Dynamic vertical workspaces per monitor.** A workspace exists while it has
  windows. One empty workspace is always at the bottom. Mod+1..9 pick by
  position on the focused monitor.
- **Overview** (Mod+O, top-left hot corner, 4-finger swipe): every workspace
  zoomed out. You can drag windows between workspaces in it.
- **Columns of several windows.** Mod+Ctrl+H/L push a window into the next
  column or out of it. Mod+G shows a column as tabs.
- **Nothing is hidden.** No special workspace, no minimize. The scratchpads are
  normal named workspaces that the scratch script moves to the focused monitor.
